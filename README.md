# Unreal Engine Splash Logos

A collection of custom-made splash screen logos inspired by the visual style of Unreal Engine. These assets are designed for personal projects, concept art, and UI mockups.

## Creation Details
- **OS:** Linux Mint Desktop Environment
- **Design Tools:** Created using native Linux desktop tools and vector editors.
- **Icon Theme:** Visual elements and styling are heavily influenced by the **Mint-Y-Sand** icon theme, giving these logos a distinct, warm aesthetic compared to standard engine branding.

## Repository Structure
The repository contains various formats (SVG, PNG) organized by version/year concepts for easy integration into your projects.
